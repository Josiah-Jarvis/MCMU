# Environment Variables

MCMU has a number of environment variables that may be used to change the default behavior.

## MCMU_MOD_PATH

This specifies the path to the mods folder. Note running `mcmu --mod-dir <mod-dir>` overrides the value stored in the environment variable.

## MCMU_GAME_VERSION

This specifies the game version to install and update mods to. Note running `mcmu update --game-version <game-version>` or mcmu install <mod> --game-version <game-version>` overrides the value stored in the environment variable.

## MCMU_MOD_LOADER

This specifies the mod loader to install and update mods for. Note running `mcmu update --loader <game-version>` or mcmu install <mod> --loader <game-version>` overrides the value stored in the environment variable.
